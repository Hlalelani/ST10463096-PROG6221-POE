# cybersecurity Awareness Chatbot

A C# console chatbot designed to educate South African citizens about cybersecurity threats and safe online practices.

## features
- voice greeting when the application starts
- ASCII art logo and enhanced console UI with colors.
- personalized user interaction
- Cybersecurity education on topics including
  * Password safety
  * Phishing scams
  * Safe browsing
  * Social engineering
  * Two-factor authentication
- Input validation and error handling
- Help menu and topic suggestions
- Clean code structure with separate classes

## Requirements
- .NET 9.0 SDK or later
- Visual Studio Code or Visual Studio 2022
- System.Windows.Extensions NuGet package

## Setup and Installation
- clone the repository
